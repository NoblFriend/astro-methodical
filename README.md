# Астрономия · гибкий учебник

Учебник из независимых блоков: читатель сам выбирает, **какие блоки статьи
видеть и в каком порядке** (теория → задачи → выводы, или сначала задачи —
как удобно). Контент пишется в Markdown с LaTeX-формулами, сайт и
LaTeX-качества PDF собираются автоматически при каждом пуше.

## Структура

```
content/
  <раздел>/                  # например 2_astrofizika
    meta.yml                 # title, code (буква для нумерации), description
    <тема>/                  # например 1_MKT
      meta.yml
      <подтема>/             # например 1Id_gas (глубина вложенности — любая)
        meta.yml
        <статья>/            # например effekt-doplera
          meta.yml           # название, описание, авторы (в т.ч. по блокам)
          01-theory.md       # блок «Обсуждение и формулы»
          02-derivations.md  # блок «Выводы формул»
          03-methods.md      # блок «Методы решения задач»
          figures/           # картинки; *.tex — TikZ-исходники
macros/macros.tex            # кастомные команды: работают в KaTeX (сайт) и в PDF
filters/environments.lua     # окружения (fenced divs) → HTML и LaTeX
latex/preamble.tex           # оформление PDF (tcolorbox-окружения, шрифты)
theme/                       # CSS/JS сайта, панелька настройки блоков
build.py                     # сборщик: content/ → site/ (+ site/pdf/)
```

Файл метаданных везде один — `meta.yml`. Роль папки определяется содержимым:
есть хотя бы один блок (`01-theory.md` и т.п.) — это **статья**, нет блоков —
**глава** (группа); вкладывать главы можно на любую глубину. Глава без статей
тоже показывается на сайте — с пометкой «в разработке».

### Порядок разделов и статей

Порядок соседей задаёт числовой префикс имени папки: `1Id_gas`,
`2raspredelenia`, … — заодно папки сортируются как надо и в файловом
менеджере. После цифр можно поставить разделитель `-`, `_`, `.` или пробел:
`1-Id_gas`, `2_raspredelenia`, `3 Общие характеристики` — как больше
нравится. **В адреса сайта префикс не попадает**: страница папки
`2raspredelenia` (или `2-raspredelenia`) живёт по адресу `…/raspredelenia/`. Папки без префикса
уходят в конец; если у двух соседей порядок совпал, он алфавитный и сборщик
предупреждает — от порядка зависит и нумерация формул (`А.1.2.…`).
Поле `order` в meta больше не используется (сборщик подскажет, если найдёт).

## Как добавить статью

```bash
make new DEST=astrofizika/fizika-zvezd/spektry/moya-statya
```

Появится папка из шаблона — заполните `meta.yml` и три блока. Правила:

- **Заголовки внутри блока** начинаются с `##` (уровень блока занят).
- **Формулы**: `$...$` и `$$...$$`. Подключён пакет **physics** — `\dv{f}{x}`,
  `\pdv`, `\abs`, `\norm`, `\qty(...)`, `\dd`, `\vb`, `\grad` и т.д. работают
  и на сайте (MathJax), и в PDF. Свои команды добавляйте в `macros/macros.tex`
  одной строкой `\newcommand` — их подхватят оба рендерера; команды из
  physics там переопределять нельзя.
- **Картинки**: TikZ-исходник кладётся в `figures/имя.tex` (самодостаточный
  документ класса `standalone`), в тексте — `![Подпись](figures/имя)`
  **без расширения**. Сборщик сам сделает SVG для сайта и PDF для печати.
  Обычные PNG/JPG вставляются как всегда, с расширением.
- **Сноски**: стандартный pandoc-синтаксис — `текст[^имя]` плюс строка
  `[^имя]: текст сноски`, или инлайн `^[текст сноски]`. На сайте сноски
  выводятся в конце своего блока, в PDF — внизу страницы.

### Нумерация формул и ссылки

Все выключные формулы (`$$...$$`) нумеруются автоматически и иерархически:
`А.1.2.1.3` = раздел **А** (буква из `code` в `meta.yml` раздела) → тема 1 →
подтема 2 → статья 1 → формула 3. Индексы определяются полем `order`,
нумерация сквозная по статье (не сбрасывается между блоками).

Чтобы сослаться на формулу, пометьте её и используйте `\eqref`:

```markdown
$$
T^2 = a^3
\label{eq:kepler3}
$$

... третий закон Кеплера $\eqref{eq:kepler3}$ даёт ...
```

Ссылки кликабельны: на сайте телепортируют к формуле, в PDF — внутренняя
гиперссылка. Работают между блоками одной статьи **и между статьями**:
если метка объявлена в другой статье, ссылка ведёт на её страницу
(в PDF — на опубликованный сайт). Метки должны быть уникальны в пределах
учебника — про совпадения сборщик предупреждает.

### Ссылки на другие статьи

`@/` + адрес статьи или группы на сайте (имена папок **без** числовых
префиксов-порядков):

```markdown
см. [функцию распределения](@/astrofizika/MKT/raspredelenia/rasprmaxwell)
```

На сайте это обычный переход между страницами, в PDF — ссылка на статью
на опубликованном сайте (адрес берётся из `url` в `config.yml`). Сборщик
предупреждает, если ссылка ведёт на несуществующую статью.

### Окружения

```markdown
::: {.definition title="Лучевая скорость"}
Текст определения.
:::

::: {.theorem title="Теорема вириала"}
Текст теоремы.
:::

::: {.law title="Первое начало термодинамики"}
Текст закона.
:::

::: {.formula-box caption="Классическая формула Доплера"}
$$ \frac{\Delta\lambda}{\lambda_0} = \frac{v_r}{c} $$
:::

::: note
Заметка мелким шрифтом с левой чертой.
:::

::: problem
Условие задачи (нумеруется автоматически).
:::

::: {.problem title="Название задачи" comment="развивает интегрирование распределений"}
У задачи могут быть название и комментарий рядом с ним — например,
какие навыки она развивает (можно писать `skills=` вместо `comment=`).
:::

::: solution
Решение — на сайте свёрнуто, в PDF печатается.
:::
```

## Локальная сборка

Нужны: Python 3 и `pandoc` **≥ 3.0** — этого достаточно, чтобы собирать сайт
и пользоваться живым предпросмотром (TikZ-картинки будут пропущены).
Для картинок и PDF нужен ещё XeLaTeX.

```bash
# Ubuntu / WSL (apt-овский pandoc бывает старым 2.x — ставьте deb с GitHub):
wget https://github.com/jgm/pandoc/releases/download/3.6.4/pandoc-3.6.4-1-amd64.deb
sudo dpkg -i pandoc-3.6.4-1-amd64.deb
# для картинок и PDF:
sudo apt install texlive-xetex texlive-latex-extra texlive-fonts-recommended \
  texlive-lang-cyrillic texlive-lang-other texlive-pictures fonts-paratype \
  dvisvgm ghostscript poppler-utils

# macOS:
brew install pandoc          # + MacTeX для картинок и PDF
```

```bash
make site     # сайт → site/
make pdf      # сайт + все PDF (статьи, все уровни групп, весь учебник)
make watch    # живой предпросмотр: правишь файл — страница сама обновляется
make serve    # просто раздать собранный site/
make search   # опционально: поисковый индекс (нужен node/npx)
```

## Публикация

GitHub Actions (`.github/workflows/build.yml`) на каждый пуш в `main`
собирает сайт с PDF и деплоит на GitHub Pages. Один раз в настройках
репозитория включите **Settings → Pages → Source: GitHub Actions** — дальше
всё само: контрибьютор мержит PR, через пару минут статья на сайте.

## Как устроена «гибкость»

Каждый блок статьи — отдельная секция на странице. Панель «Настроить блоки»
позволяет скрывать блоки и менять их порядок; выбор сохраняется в браузере
и применяется ко всем статьям. Кнопка «Печать текущего вида» отдаёт в PDF
ровно ту компоновку, которую выбрал читатель; канонические PDF со строгой
LaTeX-вёрсткой лежат рядом с каждой статьёй, подтемой и разделом.
