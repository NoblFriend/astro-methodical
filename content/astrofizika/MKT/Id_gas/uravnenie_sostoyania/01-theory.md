Уравнение состояния связывает между собой основные параметры газа. Для идеального газа уравнение состояния называют уравнением Менделеева-Клайперона:

::: {.formula-box caption="Уравнение Менделеева-Клайперона"}
$$ PV = \nu \mathcal{R} T $$
:::

Это уравнение можно записать в другой удобной форме. Вспоминая, что:
$$ \nu=\frac{N}{N_A}  \text{  } \text{ } \text{ } \text{ } \text{ } R=k N_A \text{  } \text{ } \text{ } \text{ } \text{ } n=\frac{N}{V}$$
Сразу получаем:

::: {.formula-box caption="Уравнение Менделеева-Клайперона: эквивалентная формулировка"}
$$ P=nkT $$
:::
